How to Run

Make sure Java is installed on your computer.

Compile

javac HotelBooking.java

Run

java HotelBooking

How It Works

When the program starts, it displays a menu:

===== Hotel Room Booking System =====
1. Book Room
2. Display Room Details
3. Calculate Bill
4. Check Room Status
5. Cancel Booking
6. Display Total Bookings
7. Exit

Choose an option by entering the corresponding number.

Example

To book Room 101:

Enter your choice: 1
Enter room number: 101
Enter customer name: Atharva
Enter number of days: 3

The bill will be calculated as:

3 × ₹2000 = ₹6000
